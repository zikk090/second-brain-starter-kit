## How this file works

- Keep it short. If it's getting long, the detail belongs in a dated note or a target/topic file instead, and this file should just link to it.
- Every session should end with this file updated, even if the update is just "paused here, nothing broken, pick up with X next."
- Think of it as leaving a note for a version of yourself (or an AI) with zero memory of what just happened.
