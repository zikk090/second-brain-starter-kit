# Slide generation prompt

Paste this into a fresh Claude chat (or any AI slide tool) to generate the webinar deck.

---

Create a slide deck, max 8 slides, for a live webinar titled "Build Your Second Brain in Claude — with a Security Research & Bug Bounty Focus." The audience is mostly non-technical to intermediate, learning to offload their mental overhead into an AI system. This is a PRACTICAL session — the speaker will spend most of the time live-demoing the setup on a fresh Mac user account, so these slides are the conceptual scaffolding around the demo, not a step-by-step tutorial. Keep every slide short: a headline, 2-4 bullet points max, no dense paragraphs — the speaker is talking over these, not reading them aloud.

Structure:
1. **Title/hook** — "Your Second Brain, Powered by Claude" — the promise: stop re-explaining yourself to AI every single time.
2. **The problem** — messy notes scattered everywhere, context lost between sessions, re-typing the same background info into every new chat.
3. **What a "second brain" actually is** — not just notes: a living, structured memory an AI can read from AND write to, that gets smarter the more you use it.
4. **The core recipe** (the reusable pattern, works for any AI) — one folder/vault + one instructions file the AI reads first + a few always-current index files it updates as it works.
5. **Applied to security research/bug bounty** — the same recipe becomes: target profiles, recon notes, hypotheses, ruled-out findings, a running journal — your whole research process, structured so the AI can pick up exactly where you left off.
6. **Transition to live demo** — "Let's build this from zero, right now" — signal we're switching to hands-on.
7. **What you're taking home** — mention the downloadable starter kit (link/repo) with templates and ready-to-use prompts.
8. **Thank you / Q&A** slide with contact info placeholder.

Design notes: clean, high-contrast, minimal text density, one clear visual idea per slide (icons or simple diagrams over stock photos). Output as a slide deck I can present from immediately.
