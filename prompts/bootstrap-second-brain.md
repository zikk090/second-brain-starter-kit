# Prompt: bootstrap your second brain

Use this once, in an empty folder, to have Claude build your vault structure for you instead of copying the starter files by hand.

---

I want to set up a "second brain" vault for security research and bug bounty work, in this folder. Please:

1. Create a `START-HERE.md` file that always summarizes current state in a few lines, gets overwritten (not appended to) every session, and is the first thing to read when picking work back up.
2. Create a `CLAUDE.md` file with instructions for yourself: always read `START-HERE.md` first, always update it before ending a session, keep one folder per research target, log dead ends as honestly as confirmed findings, and never submit/send/publish anything without me explicitly telling you to.
3. Create a `templates/` folder with four templates: `target-profile.md`, `hypotheses.md`, `ruled-out.md`, and `journal.md` — each one a fill-in-the-blank shape for that piece of a research workflow.
4. Explain back to me, briefly, how you'll use these files going forward.

Keep everything in plain Markdown, no special tooling required.
