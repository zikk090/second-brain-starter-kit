# Prompt: recon kickoff on a new target

Use this to start structured research on a new target, once your vault is set up.

---

I want to start researching [target name/URL] as a new bug bounty / security research target.

1. Create a new folder for it using the `templates/` structure from this vault.
2. Fill in as much of `target-profile.md` as you can from public information: what it does, likely tech stack, scope/bounty program details if one exists, and any prior disclosed vulnerabilities or CVEs you can find.
3. Suggest 3-5 entry points worth investigating first, and add them to `target-profile.md`.
4. Turn the strongest 1-2 entry points into draft entries in `hypotheses.md`, each with a concrete way to test it.
5. Update `START-HERE.md` at the vault root so a future session knows this target is now active and what the immediate next step is.

Be honest about confidence — if something is a guess rather than a verified fact, say so.
